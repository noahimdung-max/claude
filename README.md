# 마크 낚시 매크로

마인크래프트 서버의 Shift 미니게임 낚시를 자동으로 해주는 Windows 프로그램.

- 입질 감지: 마크 자막 "낚시찌 … 첨벙"(추천) 또는 찌 화면
- 미니게임: 물고기를 따라 Shift 를 자동으로 누르고 뗌 (물고기·게이지 색 상관없음)
- 낚싯대 내구도를 숫자로 읽고, 설정한 % 이하가 되면 멈춤 (수선 낚싯대는 "안 봄")
- 밝게 / 어둡게 테마

## 받기

**[Releases](../../releases/latest) 에서 `MinecraftFishingMacro.exe` 를 받아서 실행.** 설치 필요 없음.

코드 서명이 없는 무료 프로그램이라 경고가 뜰 수 있어요.

- 크롬·엣지 "흔하게 다운로드되는 파일이 아닙니다" → 다운로드 목록에서 **유지**
- Windows "PC 보호" 파란 창 → **추가 정보** → **실행**
- F7·F8 단축키가 안 먹으면 exe 를 **관리자 권한으로 실행**

## 사용법

1. 마크 설정 → 접근성 → **자막 표시 켜기**
2. 프로그램 왼쪽 **설정** → **입질 자막 → 지정하기** → 직접 낚시하다 입질 자막이 뜨면 **F7** → 자막 글자를 드래그
3. (추천) **낚싯대 내구도 → 지정하기** → F7 → 핫바 낚싯대 아래 내구도 줄을 드래그
4. 왼쪽 **낚시** → **낚시 시작** (또는 F8) → 바로 게임 창 클릭

미니게임 바는 첫 미니게임 때 자동으로 찾아요. 잘못 잡히면 **설정 → 미니게임 바 → 자동** 또는 **직접**.

## 소스로 실행

Python 3.10+ 설치 후 `minecraft_fishing/run.bat` 더블클릭.
