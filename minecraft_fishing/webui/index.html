    낚시 분석 (헛챔질·시간)

    지금까지 돌린 기록으로 헛챔질이 얼마나 있었는지, 시간이 어디에 쓰였는지, 고칠 점을 보여줘요. 문제가 있을 때 '복사'해서 보내주면 원인 찾기 쉬워요.

    '분석하기'를 누르면 여기에 나와요.

    낚싯대 자동 교체

    내구도가 멈춤 기준(설정의 %) 아래로 내려가면 아래에서 고른 칸 중 다음 칸으로 바꿔서 계속 낚아요. 고른 칸을 다 쓰면 멈춤. 칸을 눌러서 고르기.

    -

    정밀 내구도 실험

    인벤을 잠깐 열어 낚싯대에 마우스를 올리고, 툴팁의 '내구도: 57 / 64' 숫자를 그대로 읽어요. 마크에서 F3+H(고급 툴팁)를 한 번 눌러둬야 해요. 최대 내구도도 자동으로 맞춰짐.

    읽을 낚싯대 칸 (자동 = 지금 들고 있는 칸)

    모루 자동 수리 실험

    모루 쪽으로 시점을 돌려 수리 창을 열고, 낚싯대·실을 Shift+클릭 → ✓ → 수리된 낚싯대를 원래 칸으로 → 다시 물 쪽으로. 골드·실이 모자라면 멈추고 알림. 일반 모드에서만 돼요.

    낚싯대 칸

    실 칸

    모루 방향: 기록하기 (추천) 또는 각도 입력

    각도: 오른쪽·아래가 + (뒤돌기 = 180). 감도는 마크 설정 > 마우스 감도 숫자. DPI 는 상관없음.

    마크 버전
